# 孔乙己學習站｜魯迅〈孔乙己〉互動學習網站

> 一個考不上秀才的讀書人，在魯鎮咸亨酒店裡成為眾人的笑料。
> 本網站以互動視覺化帶領學生讀懂人物、寫作手法，以及那陣「快活的空氣」背後的冷漠。

適用：高中國語文・現代小說選讀　｜　介面：繁體中文／English　｜　支援：手機・平板・電腦　｜　PWA 可安裝、可離線

---

## ✨ 功能總覽

| 區塊 | 內容 |
|---|---|

## 🚀 上傳到 GitHub 並發布（GitHub Pages）

**方法 A：網頁操作（不需指令）**

1. 登入 GitHub → 右上角 **＋ → New repository**，命名例如 `kongyiji`，設為 **Public** → Create。
2. 進入新倉庫 → **Add file → Upload files**，把本資料夾內**所有檔案與 `icons` 資料夾**拖進去 → **Commit changes**。
3. 進入 **Settings → Pages** → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾 `/ (root)` → **Save**。
4. 約 1–2 分鐘後，網址會是：`https://<你的帳號>.github.io/kongyiji/`

> ⚠️ `.nojekyll` 是隱藏檔，部分系統拖曳時看不到。沒有它網站一樣能運作，可略過。

**方法 B：Git 指令**

```bash
cd kongyiji
git init
git add .
git commit -m "孔乙己學習站 first release"
git branch -M main
git remote add origin https://github.com/<你的帳號>/kongyiji.git
git push -u origin main
```

接著依方法 A 第 3 步開啟 GitHub Pages。

## 📲 安裝成 App（PWA）

- **Android / 電腦 Chrome、Edge**：開啟網址後，點網址列的「安裝」圖示，或瀏覽器選單 →「安裝應用程式」。
- **iPhone / iPad Safari**：點「分享」→「加入主畫面」。
- 第一次開啟後，主要頁面會被快取，**沒有網路也能使用**（Google Fonts 未快取時會改用系統字型）。

> Service Worker 只在 `https://` 或 `localhost` 下運作。直接雙擊開啟 `index.html` 也能使用全部功能，只是不會離線快取。

## 🛠️ 教師自訂

所有教材資料都集中在 `index.html` 的 `CONTENT DATA` 區段，用文字編輯器即可修改：

| 常數 | 用途 |
|---|---|
| `GOALS` / `STEPS` | 學習目標、學習路徑 |
| `SPOTS` | 酒店空間圖的人物說明 |
| `STAGES` | 沉淪軌跡五個階段 |
| `LAUGHS` | 笑聲雷達的場景 |
| `ATT` | 態度光譜的人物與參考位置（0＝殘暴，100＝同情） |
| `FLIPS` / `LENSES` | 文言解碼卡、敘事視角 |
| `LADDER` / `EXT` / `TECH` / `INQ` | 延伸學習內容 |
| `PLOT` / `QUOTES` / `VOCAB` / `CLOZE` | 練習區題目 |
| `QB` | 測驗題庫（`a` 為正確選項的索引，從 0 開始） |

每一筆資料都有 `zh`（中文）與 `en`（英文）兩個欄位。

**更新網站後**：請把 `sw.js` 第一行的 `CACHE = 'kongyiji-v1'` 改成 `v2`、`v3`……，學生端才會拿到新版本。

## 📚 引文與參考

- 引文出自魯迅〈孔乙己〉（1919 年 4 月發表於《新青年》，收入《吶喊》，1923）。魯迅作品已進入公有領域。
- 沉淪軌跡中的「尊嚴／身體／笑聲」數值為教學示意，不是原文數據。
- 「孔乙己的內心」視角為學習用的想像改寫，頁面上已標註，不是原文。
